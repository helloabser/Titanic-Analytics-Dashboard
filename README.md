# 🚢 Titanic Analytics Dashboard — Plotly Dash

## 📊 Project Overview

An interactive Titanic data analysis and visualization dashboard
built using Python, Pandas, Plotly and Plotly Dash.

This dashboard allows users to explore passenger information,
survival patterns, demographic characteristics and fare-related
insights through interactive charts and filters.

## 🚀 Features

- 🔍 Search and filter passenger data
- ↕️ Sort passenger records
- 📄 Pagination
- 📊 Interactive survival analysis
- 👤 Survival Rate by Gender
- 🎫 Survival Rate by Passenger Class
- 🎂 Survival Rate by Age Group
- ⚓ Survival Rate by Embarked Port
- 🌙 Dark / Light mode
- 🔄 Reset All Filters
- 📥 Download filtered data as CSV
- 📱 Mobile-friendly responsive layout
- 📈 Interactive Plotly charts
- 📋 Interactive passenger data table

## 🛠️ Technologies

- 🐍 Python
- 🐼 Pandas
- 📊 Plotly
- 🌐 Plotly Dash
- 🎨 Dash Bootstrap Components
